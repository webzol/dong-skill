# 茶知识写作与核验

用于茶知识稿的选题、补写与审稿；仅改排版时保留原意，对可疑事实单独标记，不悄悄改写。模板默认 `tea-notes`，按时间或节气组织时用 `tea-almanac`，主题 `tea-atelier`。

## 先确定这篇解决什么

一篇围绕一个读者问题展开：现象 → 有证据的解释 → 可以尝试的动作 → 适用边界。不要为了凑模板强写“四种味道”或“一天四泡”。用户只说“茶知识”而没有选题或草稿时，询问具体问题；用户要求维护茶知识技能时直接检查规则，不启动写稿流程。

| 方向 | 写作要素 | 核验重点 |
|---|---|---|
| 分类与工艺 | 茶名、分类依据、关键工序、容易混淆的名称 | 区分茶类、品种、产地与商品名；不把汤色当唯一分类依据，不编统一“发酵百分比” |
| 风味与感官 | 描述喝到的感觉、条件与差异 | 成分与感受之间的关系需有出处；不把单一物质写成某种味道的唯一来源 |
| 冲泡与调整 | 具体茶样、器具、投茶量、实际注水量、水温、计时方式 | 区分杯泡、盖碗、壶泡等场景；每次只改变一个变量，并记录结果 |
| 存茶与包装 | 茶类、包装状态、环境、计划存放时间 | 优先核对产品标签和对应标准；不跨茶类套用冷藏、密封、陈放或保质期建议 |
| 选茶与辨识 | 可观察的信息、标签、能验证的差异 | 外观、价格、年份不能单独证明品质；无检测依据不判断农残、霉变或安全性 |
| 时间与场景 | 作息、器具条件、个人口味 | 时间表仅作生活场景示例，不写成最佳饮茶时刻或健康处方 |

## 事实如何落地

- 涉及分类、工艺、化学机制、标准或存储条件时，先查可打开的原始来源：标准发布机构、科研机构、原始论文、产品标签。生产商的冲泡建议只用于对应产品，不扩展成全茶类结论。
- 将**资料结论、作者解读、个人试泡建议**分清。没有亲自试泡的数据，不写“实测”；没有出处的定量结论删去或保留为待核验，不靠“茶学通识”四个字代替来源。
- 来源有分歧时记录茶样、方法和适用条件，不拼出一个看似精确的统一数字。论文中的实验浸提条件不能直接充当日常冲泡建议。
- 不写保健功效。涉及咖啡因代谢、睡眠、孕期、药物等健康问题时需另查权威健康资料；不要从茶色或冲泡次数直接推断咖啡因含量、安全剂量。
- 配图用于解释工艺或辨识茶样时，核对图中对象；装饰图不能作为产地、品种或工艺证据。记录出处及许可，AI 示意图不冒充实拍或史料。

台账写入 `docs/sources/<date>-<slug>.md`，修订已有稿时沿用原台账，并在当天总台账链接。每条关键事实记录：

| 正文位置 / 结论 | 类型 | 来源标题与 URL | 页码 / 小节 / 表号 | 适用范围与限制 | 核验日期 |
|---|---|---|---|---|---|
| 对应段落或参数 | 资料 / 解读 / 试泡建议 | 可复查来源 | 能定位证据的位置 | 茶样与条件 | YYYY-MM-DD |

来源保留在台账，公众号正文末尾不追加来源列表。

## 参数必须能复现

冲泡建议给有依据的起始区间，附茶样、泡法和适用条件；记录试泡事实时可保留精确测量值，不能为了“只给区间”改造原始数据。

- 投茶量用 g，实际注水量用 mL；比例明确为“茶叶质量 : 水体积”，不要只写无单位的 `1:50`。
- 写清水温的测量或描述口径，器具标称容量不能当作实际注水量。
- 时间注明首泡或续泡，以及从注水开始、注水结束还是其他节点计时；注明是否完全出汤。
- 克数、注水量和比例互相校对。换器具时可以换算起点，但不承诺同比缩放就有相同风味。
- 调整顺序取决于问题和现有条件；每轮只动水温、茶量或时间中的一项，其余保持一致，再按口味决定下一步。没有通用的“先降温十度”铁律。

## 交付前检查

- 标题和首段直接进入问题；小节用短钩子，不带中文序号，不为反常识强造结论。
- 使用模板的题签、书衣线、四向表格留白；无表头参数表标签列宋体灰色、不加重。
- 图片间距统一 `margin:14px 0 20px`，无边框、圆角和图注；无 h1、灰字导语或页脚。
- 按 `../../commands/chamo.md` 串行生成；核查无占位符、图片数量正确、两份成品一致。浏览器检查窄屏表格与复制按钮，公众号粘贴效果未实际验证时明确记入待验证项。
