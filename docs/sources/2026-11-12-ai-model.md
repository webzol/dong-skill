## 设计口径

- 白底、墨黑 `#15181d`、靛蓝 `#2a55c7` 主强调、松石 `#0f8a7e` 次强调、冷灰细线 `#e7eaef`、浅冷底 `#f5f7fa`。
- 无衬线标题（`-apple-system / Helvetica Neue / PingFang SC`），正文苹方；15px / 1.95 行高 / 两端对齐 / 0.3px 字距。
- **关键数字条**：三格横排，21px 数字 + 11px 说明，中间一条竖线分隔；无卡片、无底色。
- **元信息条**：型号 · 厂商 · 状态 · 一句话定位，一行说完对象是谁。
- 表格沿用茶系列语汇：题签（居中宋体小字）+ 2px 顶线 + 宋体主色表头 + 四向留白 12px 14px，不贴边。
- 图片三类各有位置：A 官方定价 / 文档页、B 第三方榜单、C 模型卡；满栏、无边框、无圆角、**图下不写字**。
- 正文不放 h1、不放灰字导语，文末不加页脚与来源列表。
